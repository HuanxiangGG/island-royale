# 荒岛突围 · Island Royale

原创 2D 俯视角大逃杀游戏：从飞机跃下，搜集装备，穿过不断缩小的风暴，成为海岛上最后的幸存者。

## v4 内容

- **50 人规模**：离线模式为 1 名玩家加 49 名电脑对手；联机模式按实际真人数量补足电脑，总人数始终不超过 50。
- **真正共享的联机世界**：Node.js WebSocket 服务器计算移动、命中、物资和比赛结果，浏览器只提交操作。首位真人进入后等待 10 秒，满 50 名真人时立即开始。
- **独立落地、立即战斗**：可以主动跳下并控制降落方向；每位角色落地后即可移动、拾取和开火，无需等待其他人。空中角色免受枪伤，未跳伞者会自动跳下。
- **更大的探索空间**：8,400 × 8,400 地图包含九处聚落；房屋有实际门洞、独立墙体和室内物资，可以进屋搜集。
- **全岛地图**：点击小地图或按 M 查看完整地图、聚落与安全区。
- **六档品质**：普通、优秀、稀有、史诗、传说、神话。品质独立于武器类型，颜色与伤害加成不同。
- **14 款独立武器**：新增卡宾步枪、三连发步枪、轻机枪、重型狙击枪、连发霰弹枪、大口径左轮、高速冲锋枪、消音步枪和双管霰弹枪。各自具有原创枪型、涂装、伤害、射速和装填节奏；图鉴可按六种类型筛选并预览六档品质。
- **六种建筑外观**：木屋、别墅、工坊、农仓、商店、诊所，拥有不同屋顶、入口和室内陈设；保留门洞通行与屋顶淡出搜房。
- 电脑对手具有转向、加速、目标选择、障碍判断、补给和进圈行为。
- 原创海岛、可破坏物资箱、护盾、急救包、换弹、缩圈、胜负结算和本地战绩。
- 支持键盘鼠标和手机双摇杆。

本项目借鉴俯视角大逃杀这一玩法类型，未使用 Zombs Royale 的代码、标识、地图或美术资源，也与其运营方无关联。场景和武器图形由代码绘制。

## 本地运行

需要 Node.js 22 或更新版本。依赖通过锁定文件安装：

```sh
git clone https://github.com/HuanxiangGG/island-royale.git
cd island-royale
npm ci --ignore-scripts
npm start
```

打开 `http://127.0.0.1:4180`。本地服务器同时提供网页、运行时配置和 `/ws` 联机接口。用两个浏览器窗口加入联机，即可进入同一场等待中的比赛。

仅预览静态电脑对战版：

```sh
npm run preview
```

默认地址为 `http://127.0.0.1:4173`。不要直接双击 `index.html`，浏览器的模块加载规则会限制 `file://` 页面。

## 操作

| 操作 | 键盘鼠标 |
| --- | --- |
| 移动 / 降落方向 | WASD / 方向键 |
| 主动跳伞 | 空格 |
| 瞄准与开火 | 移动鼠标、鼠标左键 |
| 奔跑 | Shift |
| 拾取 / 开箱 | E |
| 换弹 | R |
| 切换装备 | 1 / 2 / 3 |
| 使用急救包 | Q |

## 检查与发布

```sh
npm test
```

测试覆盖模拟规则、品质与跳伞、独立落地后立即开火、房屋与物资、50 人比赛结束、真实双 WebSocket 客户端共享状态、建筑快照一致性、匹配补员、非法输入、过期输入、断开清理与资源限制。

GitHub Actions 在推送到 `main` 时安装锁定依赖、运行测试，再发布 `dist/`。Pages 来源应设置为 **GitHub Actions**。流程只发布静态前端，不会自动部署 VPS。

VPS 的独立 Docker Compose、Caddy 片段和后续启用步骤见 [部署说明](./deploy/README.md)。网络消息格式见 [联机协议](./deploy/protocol.md)。

## 服务限制

联机房间保存在内存中，服务重启会结束当前比赛。等待时离开会释放名额；比赛中离开后由电脑接管；没有真人连接的房间会立即清理。当前没有账号、付费、聊天、断线重连恢复或跨服务器匹配。

服务器默认限制 6 个房间、120 个连接，30 Hz 模拟、10 Hz 状态同步。已做本地功能测试，尚未完成目标 VPS 的公网延迟和大规模并发验证。

```text
  js/game.js            浏览器和服务器共用的游戏模拟
  js/renderer.js        场景、小地图与动画
  js/app.js             界面、输入和联机客户端
  config.json           静态发布时的联机开关
server/                 HTTP、WebSocket、匹配和权威模拟
tests/                  核心逻辑与真实套接字集成测试
scripts/serve.mjs       纯静态本地预览
deploy/                 独立 VPS 部署说明与 Caddy 片段
Dockerfile              生产容器
compose.yaml            独立端口与资源上限
```
